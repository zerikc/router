# Обход блокировок на Keenetic по доменам

Готовые списки доменов для маршрутизации через VPN на роутере Keenetic.

Через VPN идут только сервисы, которые заблокированы в России или сами не работают
для российских пользователей (например, Claude и ChatGPT). Остальной трафик — банки,
Госуслуги, российские и обычные сайты — идёт напрямую через провайдера.

## Установка

Нужна **KeeneticOS 4.0 или новее**: в ней появилась маршрутизация по доменам.

1. **Удалите старые IP-маршруты**: «Маршрутизация» → отметить старые маршруты → «Удалить».
2. **Добавьте списки доменов.** В веб-интерфейсе откройте маршрутизацию по доменам
   (DNS-маршруты), создайте список, вставьте содержимое файла и выберите
   VPN-подключение. Повторите для каждого файла `01`–`11`. Ненужные списки можно
   не добавлять.
3. **Добавьте Telegram.** Приложение Telegram подключается к серверам по IP, а не
   по доменам, поэтому для него нужны статические маршруты. Загрузите
   `telegram-ip.bat`: «Маршрутизация» → «Загрузить из файла», интерфейс — ваш VPN.
   Для звонков WhatsApp и Instagram так же загрузите `meta-ip.bat`.

## Настройки, без которых не заработает

Маршрутизация по доменам видит только DNS-запросы, которые идут через роутер.

- **Браузеры**: отключите «Безопасный DNS» (Chrome, Edge) и «DNS через HTTPS» (Firefox).
- **Телефоны**: на Android отключите «Частный DNS», на iPhone — «Частный узел iCloud».
- **Роутер**: включите DNS-over-TLS (компонент «Прокси-сервер DNS-over-TLS»),
  например `1.1.1.1` / `cloudflare-dns.com`, и отметьте «Игнорировать DNS провайдера».
- **IPv6**: отключите у подключения провайдера, иначе часть трафика пойдёт мимо VPN.

После изменений переподключите устройства к Wi-Fi или очистите DNS-кэш
(`ipconfig /flushdns` в Windows) и перезапустите приложения.

## Ограничения

- **Viber**: звонки могут идти напрямую по IP и не попасть в VPN. Сообщения работают.
- **Medium**: блоги на собственных доменах не попадают в список.
- **Speedtest**: сайт и приложение откроются, но замер идёт на серверы с разными
  доменами, поэтому покажет скорость провайдера, а не VPN.
- **FaceTime и iCloud** работают по IP Apple, доменами их не покрыть. Если понадобится,
  добавьте статический маршрут на подсеть `17.0.0.0/8`.

## Как добавить сайт

1. Откройте сайт в браузере, нажмите F12 и посмотрите во вкладке **Network**,
   с каких доменов он загружается.
2. Добавьте основные домены в подходящий файл и в соответствующий список на роутере.
